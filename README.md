# COSMOS

COSMOS is a LAN-first, offline-capable disaster response coordination platform. It allows groups of people co-located on the same WiFi network or mobile hotspot to:

- Chat in a shared global chatroom in real time.
- Mark locations on a shared map by dropping pins with custom labels.
- Coordinate emergency requests and aggregate local resources without requiring an internet connection.

Please refer to `PROJECT.md` for a comprehensive architectural overview, `FLOW.md` for execution flow documentation, and `decisions.md` for the technical decision log.
